# DM Consultoria

Site institucional desenvolvido para a DM Consultoria, empresa especializada em estratégia, governança, sucessão familiar e desenvolvimento organizacional para o agronegócio.

## Objetivo

Desenvolver uma presença digital profissional capaz de transmitir credibilidade, autoridade e proximidade com o setor agroindustrial, fortalecendo a marca da consultoria e facilitando o contato com potenciais clientes.

## Funcionalidades

- Landing page institucional
- Design responsivo para desktop e dispositivos móveis
- Formulário de contato integrado ao Web3Forms
- Integração com WhatsApp
- Página de confirmação de envio
- SEO básico e Open Graph para compartilhamento em redes sociais
- Favicon personalizado
- Navegação otimizada para experiência do usuário

## Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
- Web3Forms
- GitHub
- Cloudflarepages
- Cloudflare DNS
